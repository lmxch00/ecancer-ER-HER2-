# ecancer-ER-HER2- — reproducibility package (local copy)

Staging copy for the public GitHub repository
`https://github.com/lmxch00/ecancer-ER-HER2-`.

**All scripts now use RELATIVE paths** resolved from the script's own
location (`HERE = os.path.dirname(os.path.abspath(__file__))`). They are
clone-and-run portable — no absolute Windows paths remain.

## Files
- `rerun_jenci.py` — primary re-run of the JENCI ER+/HER2- pCR 2-probe
  analysis on the real local data: observed 2-probe model, bootstrap
  stability selection, Permutation A (label-shuffle) and Permutation B
  (random-gene-set), DCA, and the ER baseline.
- `extension_analysis.py` — revision extension analyses: HER2-asymmetry
  sensitivity, post-hoc power simulation, 2000-iteration random-gene-set
  permutation null, and the direct ER-status baseline AUC with bootstrap CI.
- `make_figure1.py` — regenerates Figure 1 (AUC panel + permutation-null
  histogram) and `figure1_numbers.json` from the verified 2000-perm null.
- `permutation_randomgene_null_2000.csv` — the 2000 random-gene-set
  permutation AUCs (input to `make_figure1.py`; also generated by
  `extension_analysis.py`). Included so the figure can be regenerated without
  re-running the full pipeline.
- `SEEDS.txt` — documents every random seed used across the scripts.

## Data dependency (NOT included — hosted on GEO)
The two analysis scripts read four CSVs from a `data/` subfolder placed
next to the scripts:
`X_GSE20194.csv`, `X_GSE25066.csv`, `GSE20194_clinical_labels.csv`,
`clinical_GSE25066.csv`. These are the Affymetrix HG-U133A expression
matrices and clinical labels for GSE20194 (training) and GSE25066
(validation), downloadable from GEO. They are data, not code, so they are
intentionally excluded from the code repository.

To run locally, create `data/` next to the scripts and place those four
CSVs there:
```
ecancer-ER-HER2-/
├── rerun_jenci.py
├── extension_analysis.py
├── make_figure1.py
├── data/                # <-- place the 4 GEO CSVs here (gitignored)
│   ├── X_GSE20194.csv
│   ├── X_GSE25066.csv
│   ├── GSE20194_clinical_labels.csv
│   └── clinical_GSE25066.csv
├── permutation_randomgene_null_2000.csv
├── SEEDS.txt
└── README.md
```

## Run order
```
python rerun_jenci.py          # writes bootstrap/permutation summary CSVs to script dir
python extension_analysis.py    # writes permutation_randomgene_null_2000.csv + summary CSVs
python make_figure1.py          # reads the null CSV, writes Figure_1.png + figure1_numbers.json
```
All generated CSVs/PNG are written into the script directory (the repo
root). Add them to `.gitignore` if you do not want generated artifacts in
the repo:
```
/data/
*.csv
Figure_1.png
figure1_numbers.json
```
(Keep `permutation_randomgene_null_2000.csv` tracked if you want the figure
to regenerate without re-running the full pipeline.)
